# AI GYM Buddy - Flutter Frontend

## Setup

1. Install Flutter: https://docs.flutter.dev/get-started/install
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Screens to Build

- Login
- Dashboard
- Workout
- Body Scan
- Profile

## API Base URL

Default: `http://localhost:8000` (or `http://10.0.2.2:8000` for Android emulator)

## Create Full Flutter Project

If this folder was created manually, run from `AIGymBuddy/`:

```bash
flutter create frontend --org com.aigymbuddy --project-name ai_gym_buddy
```

Then merge this pubspec.yaml dependencies into the generated one.
