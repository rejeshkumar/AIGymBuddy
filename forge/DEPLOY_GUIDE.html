Troubleshooting
🔧
If something breaks
❌ Workout generation fails
Railway → backend service → Variables → check ANTHROPIC_API_KEY has no spaces and starts with sk-ant-
❌ "Cannot connect to server"
Vercel → Settings → Environment Variables → NEXT_PUBLIC_API_URL must exactly match your Railway URL
❌ Database error on startup
DATABASE_URL must start with postgresql+asyncpg:// not postgresql:// — edit in Railway variables and redeploy
❌ Railway deploy fails
Check Root Directory is set to "backend" in Railway service settings
❌ Vercel build fails
Check Root Directory is set to "frontend" in Vercel project settings
